# とまり木

> 立ち止まって、考えて、また歩き出す。
> その途中で見つけたものを、みんなで育てていく。

とまり木は、重い腰がなかなか上がらない、ちょっとズボラな人のための iPhone アプリです。
「着手できない」を、そっと後押しします。

ふと思い立った時や、少し寂しさを感じた時に、ひと息つきに開きたくなる場所を目指しています。

## テーマ：よりみち

まっすぐ進めない日があってもいい。
立ち止まって、考えて、また歩き出す。その途中で見つけたものを、みんなで育てていく。
そんな「よりみち」を大切にしたアプリです。

## 旅のお供「くろまる」

キャラクター「くろまる」が、旅のお供としてそばにいます。
背中を押しすぎず、でも一人にはしない。そんな距離感で支えます。

## できること

### 準備済み

- 食材の管理（端末内に保存）
- 全員が投稿できる掲示板

### 目指していること

- 今やるとよいToDoの提案
- 周囲のみんなの応援と、くろまるの支援による、そっと一押しする体験
- クラウドデータベースとの接続
- ユーザーの応援資金で成り立つ「開発応援プロジェクト」

## 技術
